## 使用

1. Windows 11 22H2（build 22621）或更高版本，x64。
2. 解压完整 ZIP，运行 `AIScreenShot-win-x64/ScreenShot.App.exe`；无需安装 .NET SDK 或单独的 Windows App Runtime。
3. 先从托盘退出旧实例，再启动新包；设置与本地历史仍使用 `%LOCALAPPDATA%\AIScreenShot`。
4. AI 功能需要已登录的 Codex CLI 或已配置的 OpenAI compatible Agent 接口，图片分析需模型支持图片输入。配置和快捷键见包内 README 与 `docs/USER_GUIDE.md`。

可在 PowerShell 中核对 ZIP：

```powershell
Get-FileHash .\AIScreenShot-win-x64-20261011.zip -Algorithm SHA256
```
